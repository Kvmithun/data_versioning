# data_versioning

Here

This repository is created for practicing **Data Versioning using DVC**.

## Workflow

```text
Create Data
    │
    ▼
 DVC Add
    │
    ▼
S3 (Stores Data)
    │
    ▼
Git (.dvc File)
    │
    ▼
 GitHub
    │
    ▼
Git Checkout + DVC Pull
    │
    ▼
Restore Any Data Version
```
